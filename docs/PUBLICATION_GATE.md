# Publication Gate

This repo can be made public only if the public story is defensible.

## Allowed Public Story

This is a local, cloneable inventory proof harness for:

- ledger-backed stock tracking
- inflow/outflow recording
- reorder planning
- studio-style operations brief ingestion
- supply and order exception alerts
- CI-backed regression protection

## Disallowed Public Story

Do not claim:

- bulletproof or foolproof automation
- guaranteed employee time savings
- guaranteed cost savings
- production-verified inventory accuracy
- fully automated purchasing
- complete ERP replacement
- live customer deployment
- company endorsement

## Required Before Public Push

- Tests pass locally.
- Secret scan is clean.
- README contains the claim boundary.
- No private customer data, credentials, or proprietary exports are committed.
- Sample data is either synthetic, approved, or clearly non-sensitive.
- Public language separates implemented, locally verified, unknown, and proven.

## Required Before Stronger Claims

To claim business impact, create dated proof artifacts showing:

- baseline manual process time
- live pilot period
- source files used
- reconciliation results
- exceptions and overrides
- purchase recommendations vs. actual outcomes
- before/after admin time
